NVG Decoder

Convert Nokia NVG and SVGB icons and theme graphics (Symbian) back to SVG. Decoding runs in your browser, so your files are never uploaded.

Drop .nvg or .svgb files or folders here

Both formats are recognised by their content, so either extension works for either format.

Background

nvg2svg · Source and command-line version on GitHub

Paths, fills, linear gradients, arcs and transforms are verified against real encoder output. Strokes and radial gradients are inferred from the decompiled encoder. If a file decodes incorrectly, please open an issue and attach it.
